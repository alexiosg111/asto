# ASTO

Willkommen bei ASTO - Ihr Experte für Mobilfunktechnologie und Aufzugsservice.

## 📋 Voraussetzungen

Bevor Sie das Projekt einrichten, stellen Sie sicher, dass Sie folgende Software installiert haben:

- Git
- Ein moderner Webbrowser (Chrome, Firefox, Safari, Edge)

## 🚀 Schnellstart

### Option 1: Lokale Verwendung

1. Klonen Sie das Repository:
```bash
git clone https://github.com/alexiosg111/asto.git
cd asto
```

2. Öffnen Sie die `index.html` Datei in Ihrem Webbrowser

Das war's! Die Website sollte jetzt im Browser angezeigt werden.

### Option 2: Lokaler Server (empfohlen)

Für eine bessere Entwicklungserfahrung können Sie einen lokalen Server verwenden:

#### Mit Python 3:
```bash
python3 -m http.server 8000
```

#### Mit Python 2:
```bash
python -m SimpleHTTPServer 8000
```

#### Mit Node.js (http-server):
```bash
npx http-server -p 8000
```

#### Mit PHP:
```bash
php -S localhost:8000
```

Besuchen Sie dann `http://localhost:8000` in Ihrem Browser.

## 🎨 Anpassung

### Farben anpassen

Die Farben werden in `styles.css` definiert. Sie können die Farbverläufe ändern:

- Hauptfarben: `#667eea` bis `#764ba2` (violetter Farbverlauf)
- Hintergrundfarben: `#f8f9fa` (hellgrau), `#333` (dunkelgrau)

### Inhalt anpassen

Bearbeiten Sie `index.html`, um den Text, Links und Struktur der Website zu ändern.

## 🌐 Deployment

### GitHub Pages

1. Gehen Sie zu den Repository-Einstellungen
2. Navigieren Sie zu "Pages"
3. Wählen Sie die `main` Branch als Quelle
4. Speichern Sie die Einstellungen

Die Website wird dann unter `https://alexiosg111.github.io/asto/` verfügbar sein.

### Andere Hosting-Optionen

- **Netlify**: Drag & Drop das Projektordner auf netlify.com
- **Vercel**: Importieren Sie das Repository in Vercel
- **AWS S3**: Laden Sie die Dateien in einen S3-Bucket mit statischem Website-Hosting
