# 🚀 VSS Website - Quick Setup

## Einfaches Setup (3 Schritte)

### 1. Setup Script ausführen
```bash
# Im vss/ Ordner:
./setup.sh
```

### 2. Website starten
```bash
npm run dev
```

### 3. Im Browser öffnen
```
http://localhost:3000
```

## 📋 Alternative: Manueller Setup

```bash
# 1. Dependencies installieren
npm install

# 2. Entwicklungsserver starten
npm run dev

# 3. Website testen unter http://localhost:3000
```

## 🔧 Verfügbare Befehle

- `npm run dev` - Entwicklungsserver (zum Testen)
- `npm run build` - Production Build erstellen
- `npm run start` - Production Server starten
