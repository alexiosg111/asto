# VSS Brand Guide - Redesign Documentation

## Overview
This document provides documentation for the Vertical Service Solutions (VSS) website redesign, including the authentic brand colors and image sources used in the new design.

## Brand Colors

The VSS brand colors have been carefully selected to represent the professional nature of the company's services in elevators and mobile connectivity:

### Primary Colors
- **VSS Primary**: `#1e3a8a` - A deep blue that represents professionalism, trust, and reliability
- **VSS Secondary**: `#3b82f6` - A vibrant blue that adds energy and innovation
- **VSS Accent**: `#06b6d4` - A cyan accent color for highlights and call-to-action elements

### Neutral Colors
- **VSS Dark**: `#0f172a` - Dark background color for professional contrast
- **VSS Light**: `#f8fafc` - Light background for content sections
- **VSS Gray**: `#64748b` - Gray for text and secondary elements

### Color Usage
- **Primary Color**: Used for main branding elements, headers, and important sections
- **Secondary Color**: Used for interactive elements and secondary branding
- **Accent Color**: Used for buttons, highlights, and call-to-action elements
- **Dark Color**: Used for backgrounds and professional contrast
- **Light Color**: Used for content sections and readability
- **Gray Color**: Used for secondary text and subtle elements

## Design Elements

### Split-Screen Layout
The redesign features a split-screen layout that:
- Clearly separates the two main service areas (Elevators and Mobile Connectivity)
- Uses shader animations for visual interest
- Provides interactive hover effects
- Maintains professional aesthetics

### Shader Animations
- Subtle gradient animations that move across the screen
- Adds visual depth without distracting from content
- Uses CSS animations for performance
- Complements the professional design language

### Typography
- **Primary Font**: Inter (system fallback: sans-serif)
- **Font Weights**: 300, 400, 500, 600, 700 for hierarchy
- **Text Colors**: White on dark backgrounds, dark gray on light backgrounds
- **Headings**: Bold and prominent for clear information hierarchy

### Interactive Elements
- **Buttons**: Primary (accent color) and secondary (transparent with border)
- **Hover Effects**: Scale and shadow transitions for interactive feedback
- **Service Cards**: Hover effects with subtle shadows
- **Split Sections**: Interactive scaling on hover

## Responsive Design

The redesign maintains full responsiveness:
- **Mobile**: Stacked layout for split-screen sections
- **Tablet**: Adaptive grid layouts
- **Desktop**: Full split-screen experience
- **Breakpoints**: Optimized for all screen sizes

## Technical Implementation

### Tailwind CSS
- Updated `tailwind.config.js` with VSS brand colors
